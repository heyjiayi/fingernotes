# Fingernotes · 拇指单词

Fingernotes 是一个在浏览器中运行的互动手势单词工具。用户可以为左右手的食指、中指、无名指和小指分别输入中文或英文；摄像头识别到手掌后，文字会跟随对应指尖移动。当大拇指碰到某根手指时，网页会自动朗读这根手指上的内容。

它可以用于单词学习、儿童互动教学、语言练习、课堂演示、创意视频录制，以及体验浏览器中的实时手势识别。

## 在线体验

直接打开：**[https://heyjiayi.github.io/fingernotes/](https://heyjiayi.github.io/fingernotes/)**

在线版本不需要安装。推荐使用最新版 Chrome、Edge 或 Safari，并允许网页访问摄像头。

> 手机端请使用 Safari、Chrome 等系统浏览器打开。微信、小红书等应用的内置浏览器可能限制摄像头或语音功能。

## 主要功能

- 自定义左右手 8 根非拇指手指上的中文或英文
- 支持一只手或两只手同时识别
- 文字实时跟随对应指尖移动
- 大拇指不显示文字，只负责触发朗读
- 大拇指碰到其他手指时朗读对应内容
- 自动判断中文或英文，并选择对应语言的语音
- 提供“测试朗读”按钮，方便提前检查声音
- 输入内容自动保存在当前浏览器中
- 所有摄像头画面只在本地处理，不会上传或保存
- 项目只有一个核心 HTML 文件，无需构建和安装依赖

## 在线版使用方法

1. 打开[在线体验链接](https://heyjiayi.github.io/fingernotes/)。
2. 在“屏幕左手”和“屏幕右手”区域输入要显示的中文或英文。
3. 点击 **测试朗读 TEST VOICE**，检查扬声器和浏览器语音是否正常。
4. 点击 **开启摄像头 START CAMERA**。
5. 浏览器询问权限时，选择“允许使用摄像头”。
6. 将一只手或两只手的手掌朝向摄像头，尽量保证手指完整出现在画面中。
7. 用大拇指碰触食指、中指、无名指或小指，网页会朗读对应内容。
8. 点击 **关闭 CLOSE** 可以停止摄像头并返回单词编辑页面。

## 下载与安装

本项目不需要传统安装。下载仓库后，只需要用浏览器打开或启动一个本地网页服务器。

### 方法一：下载 ZIP

1. 打开项目仓库：[https://github.com/heyjiayi/fingernotes](https://github.com/heyjiayi/fingernotes)
2. 点击绿色的 **Code** 按钮。
3. 点击 **Download ZIP**。
4. 解压下载的压缩包。
5. 进入解压后的文件夹。

可以尝试直接双击 `index.html`。如果摄像头无法启动，请使用下面的“本地服务器运行”方法。

### 方法二：使用 Git 克隆

电脑已安装 Git 时，可以执行：

```bash
git clone https://github.com/heyjiayi/fingernotes.git
cd fingernotes
```

## 在电脑上本地运行

出于安全原因，部分浏览器会限制通过 `file://` 直接打开的网页使用摄像头。因此，推荐使用本地网页服务器。

### 使用 Python

电脑已安装 Python 3 时，在项目目录执行：

```bash
python3 -m http.server 8000
```

Windows 如果无法识别 `python3`，可以尝试：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

停止服务器时，在终端按 `Ctrl + C`。

### 使用 Node.js

电脑已安装 Node.js 时，可以执行：

```bash
npx serve .
```

然后打开终端中显示的本地网址。

## 在手机上使用

不建议把 `index.html` 下载到手机后直接打开，因为 iOS 和 Android 可能限制本地 HTML 文件访问摄像头、网络模型或语音。

手机端最稳定的方式：

1. 使用 Safari 或 Chrome 打开[在线体验链接](https://heyjiayi.github.io/fingernotes/)。
2. 允许摄像头权限。
3. 先点击“测试朗读”，再开启摄像头。
4. 如果从微信收到链接，请选择“在浏览器中打开”。

## 浏览器与设备要求

| 项目 | 建议 |
| --- | --- |
| 电脑浏览器 | 最新版 Chrome、Edge 或 Safari |
| 手机浏览器 | iPhone 使用 Safari，Android 使用 Chrome |
| 摄像头 | 内置或外接摄像头均可 |

## 摄像头权限设置

如果误点了“不允许”，可以重新开启权限：

- **Chrome / Edge：**点击地址栏左侧的网站图标，在“摄像头”中选择“允许”，然后刷新网页。
- **Safari（Mac）：**打开 Safari 设置 → 网站 → 摄像头，为当前网站选择“允许”。
- **iPhone / iPad：**打开系统设置 → Safari → 摄像头，选择“询问”或“允许”。
- **Android：**打开系统设置 → 应用 → Chrome → 权限，允许使用摄像头。

## 常见问题

### 1. 点击开启摄像头后没有画面

- 检查浏览器是否获得摄像头权限。
- 关闭正在占用摄像头的 Zoom、腾讯会议、微信视频等软件。
- 刷新页面后重新允许权限。
- 下载仓库运行时，不要只依赖 `file://`，请改用本地服务器。

### 2. 没有朗读声音

- 先点击 **测试朗读 TEST VOICE**。
- 检查电脑或手机是否静音。
- 检查当前浏览器标签页是否被静音。
- 如果正在使用 Screen Studio 等录屏软件，请确认系统音频输出和浏览器声音未被关闭。
- 刷新页面后重新测试。
- 联网语音需要网络连接；失败时网页会尝试使用浏览器自带语音。

### 3. 单词没有跟随手指

- 让整只手完整出现在画面中。
- 保持环境光线充足，避免强烈逆光。
- 手掌尽量正对摄像头，手指之间保持一定距离。
- 将手移动到画面中央，并与摄像头保持适当距离。

### 4. 碰触后连续重复朗读

触碰后先让大拇指离开该手指，再进行下一次触碰。网页使用进入和离开阈值避免同一次触碰反复触发。

### 5. 修改后的单词会不会消失

单词会保存在当前设备、当前浏览器的本地存储中。清除浏览器网站数据、使用无痕模式或更换设备后，需要重新输入。

## 隐私说明

- 摄像头画面只在用户设备的浏览器中进行实时处理。
- 项目不会主动上传、保存或录制摄像头画面。
- 自定义单词仅保存在当前浏览器的本地存储中。
- 手势识别模型和联网语音资源需要从第三方服务加载，因此首次使用需要网络。
- 如果需要录制画面，应由用户自行使用系统录屏或其他录制工具。

## 技术原理

- 使用 **MediaPipe Hand Landmarker** 识别手部关键点。
- 使用 Canvas 在摄像头画面上绘制指尖圆点和文字。
- 通过计算大拇指与其他指尖之间的距离判断触碰。
- 使用联网语音和浏览器 **Speech Synthesis API** 朗读中文或英文。
- 使用浏览器 `localStorage` 保存用户输入的单词。

## 修改项目

项目的 HTML、CSS 和 JavaScript 都在 `index.html` 中。修改后刷新浏览器即可看到效果；如果浏览器缓存了旧版本，可以使用强制刷新：

- macOS：`Command + Shift + R`
- Windows：`Ctrl + F5` 或 `Ctrl + Shift + R`
